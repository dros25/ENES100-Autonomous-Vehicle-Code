# ENES100-Autonomous-Vehicle-Code
Firmware for an autonomous ground vehicle to navigate around an arena and complete mission objectives for UMD's ENES100 course project. 

## My Contribution 
- Co-designed and wired vehicle's circuit pathways, integrating sensors and actuators for environmental data collection (pollution detection, water depth, water collection)
- Programmed vehicle navigation, obstacle avoidance, and sensor logic in C++ on the Arduino IDE utilizing UMD's ENES100 OTV library 
- Facilitated a wireless communication bridge using a Wi-Fi module to connect to an external vision system for the arena
